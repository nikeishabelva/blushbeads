# Blushie — Cute Bracelet Shop 🎀

Website toko gelang aesthetic dengan tema putih + pink, siap dipakai untuk GitHub Pages.

## Fitur
- 30 koleksi gelang
- Filter Beads, Charm, Pearl, Friendship
- Shopping cart dengan localStorage
- Checkout via WhatsApp
- Responsive untuk HP, tablet, dan desktop
- Tanpa framework
- Visual gelang dibuat dengan HTML/CSS, jadi tidak membutuhkan file gambar eksternal

## Cara upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Masuk ke **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`.
6. Save dan tunggu GitHub Pages aktif.

## Ganti nomor WhatsApp
Buka `script.js`, cari:
`const shopNumber="6281234567890";`

Ganti dengan nomor WhatsApp toko kamu dalam format internasional tanpa tanda `+`.

## Ganti nama toko
Brand saat ini: **Blushie ♡**

Kamu bisa mengganti teks `blushie` di `index.html` dan judul halaman sesuai nama toko pilihanmu.
